# 1.9.76

Swofty Launcher for F1 25 1.9.76 fixes crashes in careers whose calendar has a round on a track with no track data, and race crashes on tracks such as Brands Hatch and Le Mans. An EA app launch that Windows refuses with error 740 stops at once and names what to untick. Imported tracks stay apart from Addon Browser addons with the same id, addon pages in the Addon Browser show pictures and videos, and **Send Logs to Developers** reports how smoothly the game ran.

## Launcher

- The launcher asks for your ad privacy choices whenever none are saved, including for supporters and addon creators, and **Settings** › **General** › **Ad privacy choices** is there for everyone.
- On the EA app copy, **Play** stops before it changes anything and shows **A program is set to run as administrator** when `EALauncher.exe`, `EADesktop.exe`, `F1_25.exe` or `EAAntiCheat.GameServiceLauncher.exe` is set to **Run this program as an administrator**. The dialog names each file and what to untick, for you and under **Change settings for all users**. For `F1_25.exe` and `EAAntiCheat.GameServiceLauncher.exe`, running Swofty Launcher as administrator doesn't help, and the dialog says so. See [Programs set to run as administrator](/using/game-copies#programs-set-to-run-as-administrator).
- When Windows refuses a start with error 740 after the launch link, the launch stops at once with the same dialog. Before, the launcher waited 5 and 10 minutes for F1 25. The game folder goes back to vanilla and the session's lock is freed before the dialog shows, and the next **Play** starts straight away.
- **Send Logs to Developers** adds a **Smoothness** section to `summary.txt`: for each loader log, how many minutes got each frame pacing verdict, the newest minute's lines, the roughest minute's pacing line and the newest display line. `perf.log` has a **Pacing** table with one row a minute for the last 30 minutes, and `summary.txt` includes the latest one. See [Frame pacing](/reference/std/logging#frame-pacing).

## Addon Browser

- An addon whose creator added pictures, videos or video links shows a **Media** card at the top of its page, with a row of thumbnails to pick from. Selecting a picture or a video opens it in your browser, and a video link opens on YouTube, Vimeo or Streamable. The launcher loads the pictures from the Swofty registry and keeps them in `cache/registry/media` in the data folder, up to 256 MB. See [Media](/using/addon-browser#media).
- Creators add pictures, videos and video links in the **Gallery** section of each addon on [publish.f1.swofty.net](https://publish.f1.swofty.net), up to 12 items, each with a caption. See [Gallery](/using/addon-browser#gallery).
- The Addon Browser never updates a mod or track you imported, even when one of its addons has the same id, and doesn't install over one. The import's row on the **Addons** page shows **Kept separate**, and the Addon Browser's button reads **Your import v1.0.0 has this id**. Remove the import on the **Addons** page to install the Addon Browser addon. The Addon Browser refuses a download whose id starts with `imported-mod.`.
- **Skip this version** (**Skip these versions**) on the line next to **Update addons** keeps the versions you have. **Play** comes back, and the next version of each addon is offered again. A skipped version installs from the addon's Addon Browser page. See [Addon updates](/using/updating#addon-updates).

## Imports

- A mod or track you import installs as `<author>.<mod id>` when it is a track whose package names an author (`author_name`), such as `tester.testring`, and as `imported-mod.<mod id>` otherwise. Before, every import installed as `mod.<mod id>`. An import installed before 1.9.76 keeps its id, and importing it again replaces it in place. A zip with a `swofty.json` installs under that file's `id`. See [The addon's id](/reference/mods/tracks#the-addon-s-id).

## Career

- When a calendar addon, such as Custom Calendar, puts a season round on a track the game has no track data for, confirming the new career no longer crashes. The round is left out of the season, and `loader.log` names each one: `[career] calendar: round <n> (event <id>) is on track <id>, which this game loaded no track data for (it is not in the game's content); the round is left out of the season`. A calendar in which no round has track data is left as it is.
- A Driver Career or My Team weekend on a track with no track data record, such as a round on an imported track whose addon was removed, races Melbourne instead of crashing as its session loads. The save keeps Melbourne for that round. Before, only a Grand Prix weekend moved to Melbourne.
- When F1 25 crashes loading the first session of a new career after Custom Calendar's picker (F9) imported its calendar and left the first season without rounds, the crash window names the cause: **Custom Calendar's imported calendar left your career without a first round**. Its steps say to start the career again without the picker, or to turn Custom Calendar off before you start it.
- A profile build gives Nico Rosberg (`nico_rosberg`), whom the game ships with a head it has no head row for, a generic head of the game's that no driver wears, unless an addon adds that head. Before, F1 25 stopped at start-up when an addon put him in an entrant list.

## Core

- AI cars no longer crash the game on a track whose AI line has corner markers that its corner start and end lines don't enclose, such as Brands Hatch Grand Prix (`mod.brhgp` 1.8.0). Such a car makes its ERS decision without that corner's bonus, and `loader.log` logs the first one as `[ai] ers corner:`.
- A track with many DRS zones, such as Le Mans (`mod.lemans`) with 7, no longer crashes the game late on a lap. On a grid of up to 24 cars, the replay and flashback recorder gives a state that outgrows its buffer a larger holder, as it already did on larger grids.
- A car group in the `teams/` folder of its template's package also gets the template's archives in that folder that its `erps` don't list: `teams/common_fom.erp` for a 2025 My Team car and `teams/common.erp` for the others. `loader.log` logs `[assets] <group>: added <archive> from its template <template>`. See [Runtime assets](/reference/addons/runtime-assets).
- The core logs the game's frame pacing every minute in `loader.log`: frame times, presents, the GPU, the CPU, other processes and a verdict such as `smooth in frame times`, `stutter`, `judder`, `GPU bound` or `display mismatch`. At start it logs each display, each GPU's driver model and scheduling, the Windows settings that change frame pacing and the game's display settings. Process names are executable names only, and no line has a path or a user name. See [Frame pacing](/reference/std/logging#frame-pacing).

## Addons

- A table cell can carry a PNG in memory (`image_data`) when `hello` lists the `view.cell.image_data` capability. The launcher draws it without writing image files. Invalid or oversized data falls back to `image` and then to the cell's text. See [Pictures supplied in memory](/reference/addons/launcher-api/tables#pictures-supplied-in-memory).
- The live API's table version 4 (`SwoftyCoreLive`) adds `images()`, which gives the pixels of the badge references `team_badge_texture` returns, into a buffer the addon owns. On Steam 1.0.145.2472, `team_badge_texture` also gives a My Team career's badge. See [Images through the live API](/reference/std/live#images-through-the-live-api-table-v4).
