# 1.9.72

Swofty Launcher for F1 25 1.9.72 changes what signing in with Discord asks for and what the ads in the launcher use.

## Launcher

- Signing in with Discord now also asks for your email address. Swofty's server keeps only a one-way hash (SHA-256) of it, not the address itself.
- While you're signed in, the ads in the launcher pass that hash to RevIQ, which uses it to match ads to you, as the [ads privacy policy](https://ads.swofty.net/privacy) describes. In the EEA, the UK and Switzerland the hash is only passed on if you accept personalised ads in **Settings** > **Ad privacy choices**. Players who see no ads, such as supporters, don't pass it on.
- If you signed in before 1.9.72, the launcher uses the hash after you next sign in with Discord.
