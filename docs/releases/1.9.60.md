# 1.9.60

Swofty Launcher for F1 25 1.9.60 loads add-ons on the EA app copy of F1 25 1.0.145 and re-checks the running exe against the supported builds before add-ons load.

## Game versions

- The EA app copy of F1 25 1.0.145 (exe size 355003776) is a supported build, so add-ons load on it.
- The native loader re-checks the running exe against the supported builds. When the launcher saw an older build and the EA app replaced the exe during the wait, add-ons no longer load.
- More of the game's bindings are available: the driver academies component, the rival manager components and the team select handler.

## Telemetry

- The 2026 car telemetry and car status UDP packets are decoded.

## Add-ons

- Each screen record's root is hidden inside every other screen record's host, so one record's elements do not draw inside another's host.
- The weekend helper's options tag goes with its weekend.
- Box rule options use the stock value order when the game's value names read empty.

## Dependencies

- gpui-kit is updated from 0.9.0 to 0.9.1.
- The cargo dependency group is updated.
