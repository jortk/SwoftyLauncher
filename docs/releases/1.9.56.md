# 1.9.56

Swofty Launcher for F1 25 1.9.56 fixes Play failing with "string longer than 255 bytes", replaces the Interface scale steps with a slider and adds rules per box.

## Play

- An addon option description that is close to 255 bytes no longer stops Play. The launcher trims the text and keeps the "Applies after a restart." note. This was the "string longer than 255 bytes" error that AI Driver Behaviour 0.1.10 caused.
- Option labels, titles and the values shown on the rows are also kept within the limit.

## Interface scale

- Settings > Display has an Interface scale slider from 1% to 400%. The size applies when you let go of the slider.
- A Reset to automatic button sits next to the slider. Below 60%, a Reset interface scale button also appears at the bottom right of the window.
- Saved scales of 75 to 150% load as before.

## Fonts

- The launcher falls back to a bundled font when the system has none, which fixes the launcher crash in CrossOver bottles without fonts.

## Addons

- The addon size limit is 6 GB.
- When a late addon wrap or site targets an address the core already hooks, it is chained onto the core's hook instead of being dropped.

## For addon authors

- `content.package` 1.5 adds rules per box: fuel rules (refuelling, race fuel, parc ferme), race time limit and weekend mode, safety car, formation lap, penalties, corner cutting, grid rules and qualifying-only tyres.
