# 1.9.67

Swofty Launcher for F1 25 1.9.67 names each ray tracing structure the game builds in `loader.log` and gives each command list in a crash report's DRED section its address, the same address the build lines show.

## Core

- `loader.log` names each bottom-level ray tracing build the first time the game builds that structure with that shape, up to 800 builds: `[gfx] rtas build <n> on list 0x<list> into 0x<structure>`, then each geometry's vertex and index counts (`v<vertices>/i<indices>`) and formats.
- The DRED section of a crash report shows each command list's address after its name: `command list <name> (0x<list>)`.
