# 1.9.58

Swofty Launcher for F1 25 1.9.58 names the Skip Cutscenes crash on game version 1.0.145 and fixes a Driver Career crash at load.

## Game versions

- F1 25 1.0.145 from the EA app runs without add-ons until a later update.

## Crashes

- A crash on F1 25 version 1.0.145 with Skip Cutscenes up to 1.9.4 on in the profile gets its own crash screen, which says to turn the addon off on the Addons page until its author releases an update.
- A Driver Career whose session loaded with no entrant list crashed F1 25. The core restores the list at the session load, and stops the load instead of crashing when it cannot.
