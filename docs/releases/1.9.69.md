# 1.9.69

Swofty Launcher for F1 25 1.9.69 runs the direct start and its title skip on F1 25 1.0.145.2472.

## Core

- The direct start (`swofty test session`) and its title skip run on every build the core's addresses are checked on: Steam 1.0.141, the EA app build of the same version and Steam 1.0.145.2472. On 1.0.145.2472 a test session opens its garage instead of waiting at the title screen behind the cover.
- Every game address the direct start uses is found by a signature. `loader.log` names each one with its address on the running build, and a Grand Prix test session that can't find one fails with `one of the Grand Prix weekend's game addresses did not resolve on this build` and opens the menu.
