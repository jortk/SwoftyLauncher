# 1.9.57

Swofty Launcher for F1 25 1.9.57 supports the Steam game version 1.0.145, tells you when a game version is not supported yet, and adds bulk actions on the addons list.

## Game versions

- F1 25 Steam game version 1.0.145 is supported.
- The EA app build 1.0.145 is not supported yet. EA app copies of 1.0.145 run without addons until a later update.
- When the game is a version the launcher does not know, the line next to Play says so. Play still starts the game, which runs stock with no addons loaded and no launcher saves used. The notice goes away when you update to a launcher that supports the version.

## Profiles

- Settings > General has a Use profiles switch. Turned off, the launcher hides the profile sidebar, the profile names in the Play bar, the Addons heading and the Saves page, and keeps working on the active profile. Your profiles are not deleted, and turning the switch on brings the full interface back.

## Addons

- Hold Ctrl (Cmd on macOS) on the addons list to show a tick box on every row. Ctrl-click a row to tick it. A bar above the list has Turn on, Turn off, Uninstall and Clear for the ticked addons.
- The list keeps its scroll position after an uninstall.

## Send Logs

- `summary.txt` has a Graphics and memory section: each GPU's name, driver version and video memory, the PC's RAM and commit limit, and the newest per-minute line with RAM, commit, the game's working set and private memory, and video memory used against its budget.
- The last five crash reports are bundled, with a list of every report and minidump found.
- The game's GPU crash diagnostics (DRED) are armed.
