# 1.9.70

Swofty Launcher for F1 25 1.9.70 gives an addon's added AI team its AI data on added tracks, retries files another program has open when it moves your addons and saves, and names the ray tracing build the GPU stopped on in a crash report.

## Launcher

- **Move…** under **Settings** › **Storage** retries a file that another program has open for up to 5 seconds instead of stopping the move. It leaves out the launcher's own lock files and its embedded browser's profile, which the launcher makes again. See [Moving your addons and saves](/using/settings).

## Core

- An AI team an addon adds by copying another team's AI row, such as SWOFTY 2013's and 2014's Caterham (copied from Lotus), gets AI data on every added track. Before, practice and qualifying on a track such as Delhi showed every tyre with a lifespan of 0 laps and no AI car left the garage. The build copies the donor team's AI data at the track for the added team and logs `<track>: AI data for <package>/<team> stands in with the track's <package>/<donor>`. See [The track archive](/reference/installing-tracks#the-track-archive).
- A crash report with a GPU device removal names the ray tracing build the GPU stopped on: `the GPU stopped on list 0x<list>'s build #<k> of <n>: build …`, with that build's geometries. When the list's kept builds can't say which one it was, the line says so.
