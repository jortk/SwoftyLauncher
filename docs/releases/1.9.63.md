# 1.9.63

Swofty Launcher for F1 25 1.9.63 shows a `lang.string` record only where its `within` applies, keeps the game's ray tracing builds off address 0, hides ads from support staff and addon creators, and licenses the launcher under PolyForm Noncommercial 1.0.0.

## Addons

- A `lang.string` record with a `within` changes its text only while the current content, mode and career match it. Of the records for one key, the last one in load order that applies wins; when none applies, the game's own text shows. Before this, SWOFTY 2013's KERS wording showed in every career while SWOFTY 2013 was on.
- `loader.log` shows each change of text: `[lang] override: <key> shows "<text>" (<scope>)`, or `shows the game's own text: no record for it applies here`.

## Graphics

- The core checks every ray tracing structure the game builds. A bottom-level geometry with a null vertex, index or AABB buffer gets no primitives, and stays empty in every update of that structure. A top-level build with a null instance list builds no instances. A build with a null destination, scratch memory or update source is not sent, and postbuild info into a null buffer is dropped.
- `loader.log` shows `[gfx] rtas guard armed` at start and a `[gfx] rtas guard:` line for each such build. `SWOFTY_RTAS_GUARD=log` only logs them, and `SWOFTY_RTAS_GUARD=0` turns the guard off.

## Launcher

- Signed-in admins, Swofty Launcher Support and addon creators see no ads, like supporters.
- The launcher is licensed under PolyForm Noncommercial 1.0.0.

## Developers

- `SWOFTY_RTAS_TRACE=<n>` logs the first `n` bottom-level builds with their addresses and geometries.
