# 1.9.53

Swofty Launcher for F1 25 1.9.53 makes Send Logs reports more useful after long sessions.

## Send Logs

- A long session's game log is now sent with both its start and its end. Before, only the end was kept, so reports from long sessions were missing the start-up details (graphics card, settings, loaded programs) that help find the cause of a crash.
