# 1.9.55

Swofty Launcher for F1 25 1.9.55 adds an Interface scale setting and fixes problems with post-processing, team logos, Time Trial laps and several crashes.

## Interface scale

- Settings > Display has a new Interface scale setting with Auto, 75, 90, 100, 110, 125 and 150%. It applies at once, without restarting the launcher.

## Addons

- Addons that only add shaders now get update offers on the Play bar, like other addons.
- A special livery team kit that names no kit row is left empty instead of breaking the build.
- When an addon sets a stat id that another addon already holds, the career keeps the held registry ids.

## Post-processing

- Shader passes stay on after you pause and stay off the HUD.
- Shader passes from an addon's shader config keep that addon's ownership.
- With frame generation on, the passes now run on a copy of the swapchain at present.
- The present hook now yields to RivaTuner when an overlay addon arms it.

## Team logos

- Team logos are built into the boot archive copies of the logo arrays.
- When an addon's copies of a resource differ, each archive now gets its own copy.

## Time Trial

- Laps are filed under the cars the session loaded.
- The delta after a valid lap stays on the game's own cars and tracks.
- Eleventh team cars get the track's own AI data on addon tracks.

## Crash fixes

- Team HQ weekends no longer read past the track list when an event names a track id that is not in it.
- The Choose Driver screen no longer crashes on a focused tile with no components.
- The recognition notification no longer crashes on an empty event record list.

## For addon authors

- Addons can use native chart blocks.
- `career.season` is at 1.1, and `data_group` is optional.
- A HUD variant can set its own stock mode and stock parts.
- The native live table reads driver names.
- Bindings for the weekend options refresh and the weekend setup layout are added.
