# 1.9.68

Swofty Launcher for F1 25 1.9.68 no longer stops **Play** for a DLL that differs from Steam's copy, adds **Update turned-off addons** to Settings, checks for F1 25 1.0.145.2472 as the latest update, and lists the newest ray tracing builds of each command list in a crash report when the GPU device was removed.

## Launcher

- A DLL in the game folder that differs from Steam's copy is logged and no longer stops the launch with **Your game files have been edited**. A missing DLL, a changed `F1_25.exe` or any other changed file still does. See [Checking against Steam](/reference/restore#checking-against-steam).
- **Settings** › **General** › **Update turned-off addons**, off by default, makes **Update addons** in the **Play** bar also update every installed addon that is off, in every profile. See [Addon updates](/using/updating#addon-updates).
- The update check compares the game with 1.0.145.2472, the latest F1 25 update.

## Core

- A crash report with a GPU device removal lists the newest 64 ray tracing builds of each command list after the DRED section, the list with the newest build first. `loader.log` gets the same lines, each starting with `[gfx] rtas recent:`. A list's header has its address (`list 0x<list>`), the same address the DRED section gives its node. Each build line has `#<n>`, its place among the builds on that list in that frame, then each geometry's vertex and index counts and formats.
- `loader.log` names each bottom-level ray tracing build shape once, up to 800 shapes, instead of each structure's shapes.
- `loader.log` lists the ray tracing options in the game's hardware settings: `[gfx] the game's hardware settings have ray tracing options: pathtrace off, shadows on, …`.
