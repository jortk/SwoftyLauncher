# 1.9.59

Swofty Launcher for F1 25 1.9.59 shows which save the next Play uses and writes save copies to disk before they replace the old file.

## Saves

- A line on the play bar names the save the next **Play** uses. It reads `Saves: <profile> launcher save` when launcher saves are in use. It turns amber with the reason underneath when Play uses the game copy's own save. [Career saves](/using/career-saves) lists the reasons.
- Save copies are flushed to disk before they are renamed into place. This covers restoring a career from the vault and writing the offline journal.
- The launcher has a save backend for the EA app copy of F1 25. EA app copies of 1.0.145 still run without add-ons.

## Game versions

- F1 25 1.0.145 from the EA app runs without add-ons until a later update. This release adds more of the game's bindings for that version.
