# 1.9.54

Swofty Launcher for F1 25 1.9.54 tells you when a crash comes from version 3.0.0 of the F1 25 + 26 Aggressive AI (Alternate) addon.

## Crash screen

- Version 3.0.0 of F1 25 + 26 Aggressive AI (Alternate) crashes F1 25 while a session loads, on most tracks. That version has been taken down, but the launcher keeps it if you already updated to it. After such a crash the crash screen now names the addon and says what to do: uninstall it and install it again from the Addon Browser, or turn it off in your profile.
