# 1.9.51

Swofty Launcher for F1 25 1.9.51 fixes a crash at start-up and a state where Play and Restore both stopped working.

## Crashes

- The game no longer closes during the intro with "Your graphics driver stopped responding" when a profile has a custom team logo from the Grid Editor and a season addon that adds its own team logos.

## Play and Restore

- Play and Restore game folder work again after a PC crash or power cut left the launcher's own records half written. Before, both failed every time, and the launcher said files in the game folder were not put there by Swofty.
- When a stock game file is missing, the message now says to verify the game files in Steam or the EA app.
