# 1.9.61

Swofty Launcher for F1 25 1.9.61 runs Live State on Steam build 26566308 (F1 25 1.0.145), resolves the EA app 1.0.145 bindings against the game image, and adds new rules, HUD and live API features for add-ons.

## Game versions

- Live State recognises Steam build 26566308 (F1 25 1.0.145). It has its own build descriptor for every Live State group and selects the ERS mode offset per build, since that field moved by four bytes.
- The EA app 1.0.145 binding set resolves against the real game image. 23 bindings that exist only in the Steam build are listed as unresolvable, so add-ons that need the others bind on the EA app copy.
- The pit state change thunk (`Ai_Handle_PitStateChanged_Thunk`) binds on Steam 1.0.145, so the override that needs it binds.
- Weather, tyre and strategy sites are recorded for third-party add-ons.
- The AI racing line and the AI racing line functions are researched to L2.

## Rules

- `session.points` 1.0 sets points per box through `rules.points`.
- `content.package` 1.6 adds `rules.mandatory_tyre_change`, a mandatory tyre change per box.

## HUD

- `hud.element` 1.3 turns a group as a needle from an int leaf.

## Live API

- The live table is version 3 and adds `team_badge_texture`, the rendered team badge path the stock timing pill binds. The group is off on the EA app build.

## Add-ons

- The garage placement SDK places parked cars and mechanics independently of each other in the garage.
- The core add-on ships the Swofty startup intro, a 6 second Swofty logo video in place of the EA SPORTS startup video. The `startup_intro` setting turns it off and it is on by default. An add-on that replaces `videos/cm_f1_sting.bk2` overrides it.

## Tracks

- Tracks left out by the game's track limit are shown. Play lists the count and the first four names in a **Too many tracks** warning, and the Addons page marks each add-on that loses a track.

## Logging

- The AI corner guard log lines read `[ai] brake line` and `brake line guard` where they read `[ai] corner start` and `corner start guard`.

## Tools

- `tools/tt_expected.py` and `tools/tt_expected_db.py` generate the time trial car value tables.
