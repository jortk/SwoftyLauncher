# T156 Which code maps a car world position to the minimap texture, and which minimap.uidb fields does it use?

- Requested by: engine-re, 2026-11-17
- Status: draft

## Question
Which code maps a car world position to the minimap texture, and which minimap.uidb fields does it use?

## Hypothesis
The minimap control class (vtable 0x145879248, `Hud_MiniMapControl_Setup` 0x143819ea0) only stores flags for track_pos / track_rot / auto_zoom; the per-track data is the minimap.uidb entry hud.minimap.tracks[i] (rotation, padding, zoom_factor, dimensions, textures.corners) bound by `Hud_Minimap_BindTrackTextures` 0x143853340. The overridden control slots jump into .data1 (0x14381d340 -> 0x1516a4670, 0x14381ef40 -> 0x1516bd580, 0x14381ee40 -> 0x1516ba4e0, 0x14381e810 -> 0x1516ae200, 0x14381f030 -> 0x1516c4be0, 0x14381ea50 -> 0x1516b8850); one of them, or a function they call, should read the texture corners and the car positions each frame.

## Promotes
- A new L1/L2 row for the function that does the world -> map mapping, with the fields it reads.
- `Hud_MiniMapControl_Setup` notes (track_pos / track_rot meaning) to L3.
