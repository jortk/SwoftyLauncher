# T220 Does a car in EnteringPitBox fall back to OnTrack when it leaves the plr_pit_trgr zone?

- Requested by: engine-re, 2026-11-17
- Status: draft
- Session: (filled by the lead when batched)

## Question
When a car is in pit status 3 EnteringPitBox and leaves the TrackMarkup zone plr_pit_trgr (type 0x11) before its stop is done, does `Game_PitLane_VehicleExiting` set its status to 1 OnTrack (stop aborted)?

## Hypothesis
Static (d873a1c8): `Game_PitLane_GenerateSplines` registers exit callback 0x1434cb7f0 for markup type 0x11. It tail-jumps to `Game_PitLane_VehicleExiting` 0x1434bf980, which sets any status != 1 to 1 and posts message 0x145845968. Only `Game_PitLane_HandleEnterPitBox` sets status 3 (0x1434b8048). So a pit box placed beyond the end of the plr_pit_trgr zone, or a car pushed out of it, aborts the stop.

Pass rule: step 3 shows 3 -> 1 via VehicleExiting. Fail rule: 3 -> other status, or 1 set from another caller.
