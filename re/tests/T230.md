## Question
Does a World.layers entry whose .layer resource is missing from the ERP crash the track load or is it skipped?
One question only. If it splits into two, file two tests.

## Hypothesis
Ne_World_ReadWorldResource 0x1444c58d0 turns every layer path into a resource handle through the loader (vcall +8) and adds it with Ne_World_AddLayer 0x1444c5570; neither checks that the resource exists. A duplicate path is dropped with error 0x25. Expected: the missing layer is a dangling handle and the load goes on without that layer (no crash), but the handle resolver was not read.
