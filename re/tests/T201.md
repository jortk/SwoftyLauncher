## Question
Which ERP loader / asset group lines appear when a track archive with ADDED resources or an added World layer (V11H style) is loaded, and does the session fail there?

## Hypothesis
Duplicate eaid names are skipped silently (first archive wins, 0x143995160 returns 0); header/index errors give handleError codes 0x4f/0x54/0x56; a failed group continues only when NeAssetGroupSubTask+0x74 is set (0x144429640), otherwise its state stays 0. A crash after 'finishedLoadingERP' points to a consumer (World/layer reader), not the ERP parser.

- `finishedLoadingERP - .*` for the archive followed by a crash -> the crash is downstream of the ERP loader
