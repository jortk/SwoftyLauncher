# T223 Is the physics MATERIALS library filled once from game.dat, with DEFA as entry 0, and does a track-shipped PhysicsMaterialResource get ignored?

- Requested by: engine-re, 2026-11-17
- Status: draft
- Session: (filled by the lead when batched)

## Question
1. What are the order and the count of the global physics material library?
2. Is entry 0 DEFA?
3. Does a second PhysicsMaterialResource, loaded with a track, change the library?

## Hypothesis
Static (d873a1c8):
- `Ne_Phys_ParseMaterials` 0x1440bee90 parses only while the latch [lib+0x18] is 0, unless the reload byte [lib+0x30] is set.
- It allocates the record array once and fills it in XML order.
- `Ne_PhysicsMaterialResource_Load_Body` 0x154411b60 feeds it.
- A local dump from 2026-10-29 (vmknolle.phys-dump) lists 63 records, starting with DEFA.

## Promotes
- Ne_Phys_ParseMaterials (latch note), Ne_PhysicsMaterialResource_Load_Body, T221 (entry-0 fallback).

## Build
- exe: F1_25.exe sha256 d873a1c8d2044cef...
- plugins: a read-only probe on 0x1440bee90 that logs per call:
  - the latch and the reload byte;
  - the library count ([[[lib+0x28]+8]+0x28]+0x10);
  - the first 4 codes.
  The probe also logs the call count of 0x154411b60.

## Trace config
Probe on entry and return of 0x1440bee90 and on entry of 0x154411b60; no periodic sampling.

## User steps
1. Start the game to the main menu.
2. Load a stock track in Grand Prix practice.
3. Return to the menu.
4. Load a second track.

## Expected log lines
- Exactly one parse with latch=0 and count=63, first code DEFA.
- Any later call shows latch=1 and no parse.

Pass rule: one fill, DEFA first, later loads skipped. Fail rule: a reparse or a different entry 0.
