# T242 Which time-of-day scenario is current in each category during a race, and which post splines load?

- Requested by: engine-re, 2026-11-17
- Status: draft
- Session: (filled by the lead when batched)

## Question
In a Grand Prix session, which scenario is current (clock+0x1d8) and which is the fallback (clock+0x1dc) in the four category clocks `TimeOfDaySystem+0x1c18 + c*0x288` (c = 0 TimeOfDay, 1 Weather, 2 Camera, 3 Grading) and in the active weather dataset clock `+0x2c8 + d*0x288`? Which file backs the resource `eaid://ego_package/postprocess.psplines` (slot 8 of `Render_PostProcess_LoadResources`)?

## Hypothesis
Static reading (render.md#time-of-day-curve-files): every clock starts with `_master` (0x99fac8f0) as default and fallback; `Game_TodData_ParseTodd` then sets the fallback to the last flagged scenario of the file (timeofday_debug, weather_Clear-Clear_a, camera_debug, grading_cinematic). The weather dataset clock gets `weather_<From>-<To>_a` from the stitch, the camera clock `camera_<type>` from `Game_TimeOfDaySystem_UpdateCameraScenario`. Open: whether the TimeOfDay category stays on `_master` (then its 154 constant keys win for every key it defines, because `Game_TimeOfDaySystem_FinaliseTimeOfDay` takes the first category that has the key) or switches to `timeofday_debug` (hour curves). The psplines id is expected to resolve to `ego_package/postprocess/track_default/default.psplines`.
