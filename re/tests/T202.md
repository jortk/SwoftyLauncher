## Hypothesis
All track paths are tracks.track_resource templates expanded with FILENAME = fileName (record+0x78), FOLDER = record+0x180, BASETRACK = baseTrack (record+0x128) by Game_TrackRecord_ExpandPathTokens_Body 0x14f369fa0; the DRS layer alone is fixed to eaid://environment_package/tracks/<fileName>/wep/<fileName>-drs.layer (0x14299b480). A new code therefore loads from its own folder when its track_resource templates point there.
