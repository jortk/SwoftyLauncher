# T210 Does a TrackMarkup with two marshal_light_zone sets (duplicate IDs, overlapping ranges) give a permanent yellow?

- Requested by: engine-re, 2026-11-17
- Status: draft
- Session: (filled by the lead when batched)

## Question
With 24 marshal_light_zone items (14 + 10 with IDs 1..14 and 1..10, overlapping ranges) in one TrackMarkup, how many marshal zones does the MarshalZoneMonitor build, which zone gets each car, and does a single slow car produce a yellow that never clears?

## Hypothesis
Static: Sess_MarshalZoneMonitor_Init 0x14357e780 builds one zone per item in list order with list-index neighbours (+0x70..+0x88, cyclic), Sess_MarshalZone_UpdateZoneVehicles 0x14357c2c0 puts a car only into the first matching zone in list order, and Sess_MarshalLights_AssignToZones 0x142c76da0 maps lights by item ID. So the second set never holds cars, and zones of both sets are each other's neighbours at the seams. In-game report (F1_TrackLab Hockenheim R44, UDP): only 3 zones and permanent yellow; that count is not explained statically (the UDP session packet builder was not traced).

## Promotes
- `Sess_MarshalZoneMonitor_Init`, `Sess_MarshalZone_UpdateZoneVehicles`, `Sess_MarshalLights_AssignToZones` notes to L3 if the zone count and assignment match.

## Build
- exe: F1_25.exe sha256 d873a1c8d2044cef... (must equal `re/db/signatures.json` build)
- data: a stock track common ERP whose TM has a second copy of the marshal_light_zone elements with IDs restarting at 1 (test package, never the game install).

## Trace config
Hooks (trace only, by address): 0x14357e780 return -> dump [this+0x88..+0x90] count and per zone item Start/End/ID; 0x14357c2c0 return every 1 s -> per zone +0x40 bit mask.

## User steps
1. Load the test package in Grand Prix, practice, one AI car.
2. Drive one lap at normal speed, then stop on track for 30 s in a range covered by both sets.
3. Note when the yellow flag shows and clears.

## Expected log lines
- `zones=24` -> one zone per item (list order).
- car bit only in zones 0..13 -> first-match assignment.
Pass rule: zone count and first-match assignment as above. Fail rule: other count or a car in a zone of the second set.
