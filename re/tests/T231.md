## Question
What does an AudioEmitter with an unknown Wwise event name (audio.event.01) do in game: silence, log only, or crash?
One question only. If it splits into two, file two tests.

## Hypothesis
The AudioEmitter reader (Game_Read_AudioConfig_2 0x1443e6db0) stores Game_Get_WwiseIdFromString(name) without checking the bank. The id has no event in metadata.bnk; Wwise PostEvent with an unknown id normally returns AK_INVALID_PLAYING_ID and plays nothing.
